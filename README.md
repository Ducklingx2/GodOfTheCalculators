# God Of The Calculators

> Because opening your phone's calculator is *clearly* too much effort.

Welcome to **Calculator**, a project dedicated to answering one very important question:

> *"Can I calculate that?"*

The answer is probably **yes**.

If not...

...give me a week.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚡ Powers
- 📦 Modulo
- 🧠 Parentheses (they're smarter than they look)
- 💥 The ability to divide by zero.
  - Just kidding.
  - Don't.

## 🤔 Why?

Because every programmer eventually thinks:

> "I could make a calculator."

Most stop after adding `2 + 2`.

I took that personally.

## 🚀 Installation

```bash
git clone https://github.com/yourusername/calculator.git
cd calculator
python main.py
```

## 💻 Example

```text
> 8 * (6 + 4)

80
```
